**original_problem_statement:**
The user wants to build a simple, minimal, and mobile-first Expo app to help users prepare for the OPSC (Odisha Public Service Commission) exam.

After the initial build, the user provided critical feedback on the question quality, stating that the existing questions are repetitive, too simple, and do not cover a wide enough spectrum of topics (e.g., world maps, current affairs). The user provided four real OPSC exam question papers (PDFs) as a benchmark for the required complexity and style.

**PRODUCT REQUIREMENTS:**

1.  **High-Quality Questions:** The core requirement is to replace the entire question bank with ~2,600+ unique, non-repetitive, and challenging questions that match the difficulty and format of real OPSC exams. This includes multi-statement questions, matching pairs, and questions covering a broad range of topics.
2.  **Negative Marking:** Implement a negative marking system where 0.25 marks are deducted for each incorrect answer. This should be reflected in the final score and communicated to the user on the pre-exam and results screens.
3.  **Answer Feedback:** During an exam, when a user answers a question, the selected option should be highlighted (green for correct, red for incorrect) and the correct option should also be highlighted in green for 1-2 seconds before advancing to the next question.
4.  **Answer Resubmission Toggle:** On the pre-exam screen, provide a toggle/checkbox that allows users to enable or disable the ability to go back and change previously answered questions. If disabled, the Previous button should be hidden during the exam.
5.  **Answer Key Review:** After completing a test, the results modal should have a button to view a full answer key. This key should display all questions, the user's answer, the correct answer, and an explanation for each question.
6.  **UI Text Update:** The subject cards on the home screen should be updated to reflect the new paper structure (e.g., 25 Sample Papers + 1 Master).

**User's preferred language**: English
